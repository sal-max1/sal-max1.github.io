# Saloni Sethi portfolio

A small static website built with HTML and CSS. No framework or build step is required.

## Edit the site

- Edit `index.html` to change names, article titles, descriptions and links.
- Edit `style.css` to change colors, spacing and typography.
- Upload both files to the root of the GitHub Pages repository and commit the changes.

## Publish

The site is configured for GitHub Pages deployment from the repository root (`main` branch).
