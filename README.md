# Personal newsroom portfolio — GitHub Pages starter

This is a hand-coded static website starter using HTML and CSS. It is designed for GitHub Pages and has no build step.

## Before publishing
1. Replace `[Your Name]`, `[EMAIL_ADDRESS]`, `[RESUME_URL]`, and all other bracketed placeholders.
2. Replace article/project placeholders with the exact public URLs.
3. Confirm every project description and metric before publishing.
4. Add screenshots or graphics only where they strengthen a specific project page.

## Publish with GitHub Pages
1. Create a GitHub repository named exactly `YOURUSERNAME.github.io`.
2. Upload the contents of this folder to the repository root (so `index.html` is at the top level).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. After GitHub finishes deploying, visit `https://YOURUSERNAME.github.io`.

## Notes
- This starter is plain HTML/CSS: no AI website builder, framework, or JavaScript dependency.
- Google Fonts are loaded externally; the page falls back to system fonts if unavailable.
- Keep project descriptions precise. Mark ongoing research as ongoing and do not publish preliminary findings as conclusions.
